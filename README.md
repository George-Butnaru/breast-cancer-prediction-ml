# Breast Cancer Prediction Using Machine Learning

## 📖 Project Overview

This project was completed as part of the **Data Science Principles** module during my MSc Computer Science studies.

The objective was to investigate how machine learning algorithms can classify breast cancer cases using the Wisconsin Breast Cancer dataset.

Two classification models were developed and evaluated using R.

---

## 🚀 Features

- Data preprocessing
- Exploratory data analysis
- Decision Tree classification
- Random Forest classification
- Confusion Matrix evaluation
- ROC Curve analysis
- AUC performance evaluation
